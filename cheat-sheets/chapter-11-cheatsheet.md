## Chapter 11 Cheat Sheet: Full Exam Simulation & Scoring Strategy

### Exam Format
| Attribute | Value |
|---|---|
| Total questions | 63 |
| Total time | 120 minutes |
| Avg. time/question | ~114 sec (1 min 54 sec) |
| Scaled score range | 100-1000 |
| Passing threshold | 720 |
| Delivery | OnVUE online proctored |

### Pacing Checkpoints (114 sec/question budget)
| Question # | Ideal Elapsed Time |
|---|---|
| Q16 | ~30 min |
| Q32 | ~60 min |
| Q48 | ~90 min |
| Q63 | ~120 min |

Rule: more than 5 min behind at any checkpoint → switch to skip-and-flag mode (answer best guess, flag, move on).

### Single vs Multiple-Response Cues
| Cue | Meaning |
|---|---|
| Round radio buttons | Single answer only |
| Square checkboxes | Multiple-response — prompt states exact count required |
| No partial credit | Multi-response is all-or-nothing on exact correct set |

### Flagging & Review Strategy
1. Answer every question with a best guess — never leave blank.
2. Flag only genuinely uncertain items.
3. Use remaining time to revisit flagged items, prioritized by domain weight (highest weight first).
4. Never leave a flagged item unresolved if time allows a guess refinement.

### Scaled Score vs Raw Percentage
- Scaled score (100-1000) adjusts for item difficulty differences across exam forms — it is **not** a raw percentage.
- A 720 passing threshold does **not** equal "72% of questions correct"; the underlying raw cut score is set through psychometric equating and is not publicly disclosed.
- Domain-level performance feedback (if provided) should guide retake study priority, not the single scaled number alone.

### OnVUE Day-of-Exam Checklist
- Valid government-issued photo ID ready.
- Clear desk — no papers, phones, second monitors, or smartwatches.
- Perform required 360° webcam room scan when prompted.
- Close all background applications before launching the exam.
- Keep microphone active for the entire session.
- Stable, wired internet connection recommended over Wi-Fi.
- No talking, leaving the frame, or reading aloud during the exam.

### Review Priority Formula
Priority = (Domain Weight %) × (Personal Weak-Area Confidence Gap)
Higher-weighted domains with lower confidence get reviewed first when time is limited.

# CCAR-P Exam Overview Cheat Sheet

## Exam Format
| Attribute | Value |
|---|---|
| Questions | 63 |
| Time limit | 120 minutes |
| Delivery | Pearson VUE OnVUE (remote) or test center |
| Scoring model | Scaled, 100-1000 |
| Passing threshold | 720 |
| Credential validity | 12 months |
| Renewal | Free if completed on time |
| Registration | Anthropic Partner Academy portal |

## Prerequisites (Recommended, NOT Required)
| Recommendation | Threshold |
|---|---|
| Architecture experience | 3+ years |
| Production Claude experience | 6+ months |
| Formal prerequisite certification | None |

**Exam note:** No prerequisite gate exists — anyone can register. The recommended experience predicts readiness, not eligibility.

## Scaled Score vs Raw Percentage
- Raw correct-answer count is **not** directly converted to pass/fail.
- Scaled score reflects **domain-weighted** performance.
- A high raw percentage concentrated in low-weight domains can still fail if high-weight domains (e.g., governance, stakeholder management) are weak.

**Common mistake:** Assuming 55/63 correct (~87%) guarantees a pass. It does not — domain weighting can produce a scaled score below 720.

## Domain Weighting Highlight
| Domain Group | Combined Weight |
|---|---|
| Governance + Stakeholder + Developer Enablement | ~35% |
| Remaining domains | ~65% split across the other four domains |

**Exam note:** The 35% block is the single largest combined weighting — prioritize study time here relative to its size.

## Professional vs Foundations Judgment Bar
| Level | Tests |
|---|---|
| Foundations | Recall, syntax, basic definitions |
| CCAR-P (Professional) | Defense and justification of architectural trade-off decisions under real constraints |

**Common mistake:** Studying CCAR-P like a syntax-memorization exam. Questions are scenario-driven and expect reasoned trade-off justification, not command recall.

## Registration & Renewal Flow
1. Register via **Anthropic Partner Academy portal**.
2. Schedule delivery through **Pearson VUE** (OnVUE or test center).
3. Pass with scaled score ≥ **720**.
4. Credential valid **12 months**.
5. Renew **on time** → free. Miss the window → lapse, retake required.

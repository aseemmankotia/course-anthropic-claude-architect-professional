# Chapter 7 Lab: Governance, Safety, and Risk Management

**Estimated time:** 45 minutes

## Exercise

Write a governance and safety control set for a regulated healthcare deployment, including data residency controls, least-privilege MCP tool scoping, injection-defense measures, and an audit-log schema

## Key takeaway

Governance in regulated deployments is a first-class architecture concern, enforced through system-level controls, not policy documents alone.

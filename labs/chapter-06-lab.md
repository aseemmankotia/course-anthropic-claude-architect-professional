# Chapter 6 Lab: Evaluation, Testing, and Optimization

**Estimated time:** 45 minutes

## Exercise

Build an evaluation harness with a 50-item golden set, an LLM-as-judge rubric, and a regression test that flags quality drift after a prompt change, then apply prompt caching to reduce token cost

## Key takeaway

Rigorous, repeatable evaluation and regression testing — not spot-checking — is what the exam expects of a senior architect.

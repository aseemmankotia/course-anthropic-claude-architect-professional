# Chapter 2 Lab: Integration I: APIs, Middleware, and MCP Server Design

**Estimated time:** 45 minutes

## Exercise

Design and diagram an MCP server that exposes a legacy SOAP-based inventory system as three scoped tools, then implement a minimal MCP server stub using the MCP SDK

## Key takeaway

Enterprise integration success depends on scoped, least-privilege MCP tool design, not raw API connectivity.

# Chapter 3 Lab: Integration II: Retrieval, Identity, and Event-Driven Patterns

**Estimated time:** 40 minutes

## Exercise

Architect an identity-propagation flow where a Claude agent acts on behalf of an authenticated employee through an MCP server with OAuth token exchange, and build a batch job using the Message Batches API

## Key takeaway

Choose integration mode (real-time, event-driven, batch) and identity model based on latency need, cost, and auditability, not by defaulting to synchronous calls.

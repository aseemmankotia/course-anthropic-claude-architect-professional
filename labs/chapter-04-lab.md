# Chapter 4 Lab: Solution Design I: Model Selection and Agent Architectures

**Estimated time:** 40 minutes

## Exercise

Given three enterprise scenarios (customer support triage, financial document analysis, legal contract review), select and justify a model tier and workflow/agent/multi-agent pattern for each using a decision matrix

## Key takeaway

Senior architects justify model and agent-pattern choices with explicit cost/latency/quality tradeoffs, not default complexity.

# Chapter 9 Lab: Claude Models, Prompting, and Context Engineering at Scale

**Estimated time:** 40 minutes

## Exercise

Build a long-running agent session that exceeds the context window, implement a compaction/summarization strategy to preserve key state, and enforce structured JSON output consumed by a downstream service

## Key takeaway

Context and model-steering decisions at scale require deliberate engineering — compaction, memory design, and structured output validation — not default settings.
